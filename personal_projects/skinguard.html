SkinGuard

BANA 274 · UC Irvine, Paul Merage School of Business

Python Machine Learning Computer Vision Healthcare Analytics Web Development

Overview

SkinGuard is an AI-powered skin cancer screening tool that analyzes dermoscopy and clinical images to assess risk for three malignant conditions: melanoma, basal cell carcinoma, and actinic keratosis / squamous cell carcinoma. The system produces probability estimates for each condition and categorizes overall risk as low, medium, or high — providing an accessible first-pass screening aid for users who may not have immediate access to a dermatologist.

The project is deployed as a web application and available on both desktop and mobile browsers. Note: this tool is designed for research and educational purposes only and is not a substitute for professional medical diagnosis.

Technical Approach

The pipeline is built around Google Gemini Vision API, which powers the image analysis and probability scoring. Before any image reaches the model, an automatic quality assessment step rejects poor-quality submissions — blurry, low-resolution, or incorrectly formatted images — ensuring the model only processes actionable input.

  • Backend developed in Python 3.10+, handling image ingestion, quality checks, API calls, and response formatting
  • Frontend built with JavaScript, HTML, and CSS for a responsive, accessible interface supporting JPG, PNG, and WebP uploads
  • Application deployed via Render (free tier)
  • Independent probability estimates computed per condition, surfaced alongside a summary risk tier

Key Takeaways

Deploying a health-adjacent AI tool forced hard tradeoffs early: image quality control, uncertainty communication, and clinical disclaimers had to be load-bearing from day one, not added later as polish.

Keeping the Python API layer decoupled from the UI made iterating on both significantly faster — changes to the model pipeline didn't require touching the frontend and vice versa.
