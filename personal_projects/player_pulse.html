Player Pulse

Valorant Customer Spend Analysis — Personal Project

Overview

Player Pulse is a lifecycle segmentation framework built for live-service games, using synthetic Valorant-style player behavior data. The goal was to identify distinct player segments based on engagement and spending patterns, then model the drivers of in-game purchases to surface actionable retention and monetization insights.

Tech Stack

  • Python — data cleaning, EDA, and feature engineering
  • SQL — querying and aggregating player behavior data
  • Random Forest — predicting customer spend and identifying key drivers
  • Tableau — interactive dashboards for lifecycle segment visualization

Analytical Approach

  1. Generated and cleaned synthetic Valorant-style player behavior CSV data
  2. Performed exploratory data analysis to understand spend distribution and engagement trends
  3. Segmented players into lifecycle stages (new, active, at-risk, churned) using behavioral metrics
  4. Built Random Forest models to predict spend and rank feature importance
  5. Exported segment data to Tableau for dashboard development and storytelling
  6. Synthesized findings into a PDF report with recommendations for retention strategy

Key Findings

The analysis revealed that playtime frequency and match win rate were the strongest predictors of in-game spend. At-risk players — identified by declining session frequency — showed significantly lower spend in the 30 days prior to churn, suggesting a viable early-intervention window for re-engagement campaigns.
